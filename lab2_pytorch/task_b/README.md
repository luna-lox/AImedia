# Operation: EchoTrace fixed

`submission.csv` — ответ для загрузки в задачу B. Каждой картинке соответствует ровно шесть других картинок; имена и расширения сохранены.

## Метод

1. Преобразование изображений в RGB.
2. Стандартная предобработка ResNet50 ImageNet V2: resize 232, центральный crop 224, нормализация ImageNet.
3. Предобученная ResNet-50 без финального классификатора выдаёт 2048 признаков.
4. L2-нормализация признаков и поиск шести максимальных косинусных сходств. Сам запрос исключается.
5. Проверка полноты CSV, существования имён, отсутствия повторов и рекомендаций самого себя.

Модель не обучается на этом архиве. Порог 0.5 не подтверждён: локально нет эталонных соседей, оценку выдаёт контест. Ограничения времени и памяти из условия не являются временем подготовки CSV локально.

Документация модели: https://docs.pytorch.org/vision/0.16/models/generated/torchvision.models.resnet50.html

## Воспроизведение

Зависимости: torch, torchvision, numpy, Pillow. Изображения из dataset.zip находятся в `data/`. Веса — `weights/resnet50-11ad3fa6.pth`, официальный источник: https://download.pytorch.org/models/resnet50-11ad3fa6.pth. Скрипт проверяет префикс SHA256 весов.

Запуск из папки проекта:

```sh
python3 task_b/retrieve.py
```

Признаки кэшируются в `features.npz`. При смене модели или предобработки этот кэш нужно удалить перед повторным расчётом. `neighbours.jpg` показывает запрос слева и шесть рекомендаций справа; `validation.json` содержит результаты проверок формата.
