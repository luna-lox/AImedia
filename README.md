# Трекинг объекта классическими методами CV

Практическая работа: программа отмечает положение объекта на каждом кадре видео
и рисует его путь — на каждом следующем кадре видны отметки (крестики) с
предыдущих кадров.

Всё сделано на «классике» OpenCV: `cv2.inRange()` / `cv2.threshold()`,
морфология, `cv2.findContours()` + `cv2.moments()` для центроида и примитивы
`cv2.drawMarker()` / `cv2.line()` / `cv2.circle()` / `cv2.rectangle()` для отрисовки.
Никаких нейросетей и готовых трекеров из `cv2.legacy`.

## Как пользоваться

1. Подобрать пороги под свой объект (ползунки + клик мышью по объекту на кадре):

```bash
python3 calibrate.py my_video.mp4
```

Окно показывает три панели: кадр, кадр по маске и саму маску. Кликните по
объекту — диапазон HSV подставится автоматически, дальше подправьте ползунками
так, чтобы белым в маске остался только объект. Клавиша `s` печатает готовую
команду, `q` — выход.

2. Прогнать трекер и сохранить результат:

```bash
python3 tracker.py my_video.mp4 -o result.mp4 --hsv-lower 15,120,120 --hsv-upper 35,255,255
```

Если цвет объекта «стандартный», можно обойтись пресетом:

```bash
python3 tracker.py my_video.mp4 -o result.mp4 --color red
```

Доступные пресеты: `red`, `orange`, `yellow`, `green`, `cyan`, `blue`, `purple`, `pink`.

## Как это работает

Для каждого кадра:

1. **Сглаживание** — `cv2.GaussianBlur()`, чтобы шум не давал ложных пикселей в маске.
2. **Бинаризация** — `cv2.inRange()` по HSV (режим `--mode color`) либо
   `cv2.threshold()` по яркости (`--mode bright` / `--mode dark`).
   HSV удобнее RGB: тон объекта почти не меняется при изменении освещения.
   Для красного цвета тон «заворачивается» через 0, поэтому при `H_min > H_max`
   маска собирается из двух диапазонов через `cv2.bitwise_or()`.
3. **Морфология** — `MORPH_OPEN` убирает одиночные пиксели шума, `MORPH_CLOSE`
   залепляет дырки внутри объекта (блики, тени).
4. **Поиск объекта** — `cv2.findContours()`, берётся контур наибольшей площади;
   контуры мельче `--min-area` отбрасываются. Центроид считается через моменты:
   `cx = M["m10"]/M["m00"]`, `cy = M["m01"]/M["m00"]`.
5. **Отрисовка пути** — все центроиды хранятся в `deque`. На кадре рисуются
   линия между последовательными позициями и крестики на позициях с предыдущих
   кадров; цвет плавно меняется от голубого (старые отметки) к красному (свежие).
   Текущее положение выделяется жёлтой рамкой и кружком.
   Если объект на кадре не найден, в след пишется `None` — линия рвётся,
   а на панели выводится `OBJECT LOST`.

Небольшое экспоненциальное сглаживание координат (`--smooth`) убирает дрожание
центроида; `--smooth 0` полностью его отключает.

## Параметры

| Параметр | Что делает | По умолчанию |
|----------|------------|--------------|
| `-o, --output` | файл результата | — (без записи) |
| `--mode` | `color` (inRange по HSV), `bright` / `dark` (threshold по яркости) | `color` |
| `--color` | готовый HSV-пресет | `orange` |
| `--hsv-lower`, `--hsv-upper` | границы HSV вида `H,S,V`, перекрывают пресет | — |
| `--thresh` | порог яркости для `bright` / `dark` | `200` |
| `--min-area` | минимальная площадь контура, px | `150` |
| `--blur`, `--morph` | размеры ядер размытия и морфологии | `5`, `5` |
| `--smooth` | сглаживание центроида, `0` — выключено | `0.35` |
| `--trail` | длина следа в кадрах, `0` — весь путь | `0` |
| `--mark-every` | ставить отметку каждый N-й кадр | `3` |
| `--marker` | форма отметки: `cross`, `tilted`, `star`, `square`, `diamond`, `triangle` | `tilted` |
| `--marker-size` | размер отметки, px | `12` |
| `--scale`, `--start`, `--end` | масштаб кадра и обрезка по секундам | `1.0`, `0`, — |
| `--debug` | дописать справа бинарную маску | выкл. |
| `--show` | показывать окно во время обработки | выкл. |

## Проверка без своего видео

В репозитории есть генератор синтетического ролика — оранжевый мяч летает по
пёстрому фону среди цветных отвлекателей. Он нужен только для самопроверки
пайплайна:

```bash
python3 make_sample_video.py sample.mp4 --seconds 12
python3 tracker.py sample.mp4 -o sample_result.mp4 --color orange --min-area 200
# Готово: 360 кадров, объект найден на 360 (100.0%)
```

## Советы по съёмке своего видео

- Объект должен заметно отличаться по цвету от фона (яркий мяч, кубик, маркер).
- Ровный свет без пересветов: блик «выбивает» насыщенность, и пиксели выпадают из `inRange()`.
- В кадре не должно быть больших предметов того же цвета — берётся самый крупный контур.
- Снимать лучше со штатива/неподвижно: тогда путь объекта читается нагляднее.
- Если объект теряется — расширьте диапазон по `S` и `V` (а не по `H`) и уменьшите `--min-area`.
